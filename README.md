# Guess the Number (Угадай число)

Консольная игра на C++, где компьютер загадывает число, а игрок пытается его угадать.

## Возможности

- Случайное число от 1 до `max` (ты сам задаёшь верхнюю границу).
- Подсказки «Больше» / «Меньше» после каждой попытки.
- Счётчик попыток.
- Цветной вывод ошибок (через WinAPI).
- Обработка некорректного ввода (через исключения `std::istream::failure`).

## Как играть

1. Запусти программу.
2. Введи число `max` — до скольки компьютер загадает число (от 1 до `max`).
3. Угадывай, вводя числа.
4. Программа подскажет «Больше» или «Меньше».
5. Когда угадаешь — увидишь количество попыток.
6. Чтобы выйти — закрой окно или введи не число (сработает `catch`).
